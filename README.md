# WT-4 ASP.NET Core MVC

Лабораторная работа WT-4 по дисциплине «Web-технологии».

Предметная область: **Игровой сервис / Турниры**.

## Локальный запуск

```bash
dotnet run
```

Приложение использует ASP.NET Core MVC, Razor Views, Bootstrap и хранение данных в памяти приложения.

## Основные маршруты

- `/` — главная страница;
- `/Players/Index` — каталог игроков;
- `/Players/Details/1` — подробности игрока;
- `/Players/Create` — добавление игрока;
- `/Players/Edit/1` — редактирование игрока;
- `/Players/Top` — дополнительная операция: топ-3 по рейтингу.
